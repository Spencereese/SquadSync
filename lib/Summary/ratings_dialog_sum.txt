File 2: rating_dialog.dart
Purpose: Provides a dialog for rating squad members on various metrics post-game.
Key Components:
RatingDialog (class): Static method showRatingDialog for rating UI.
_buildSlider: Slider widget for rating input (Vibes, Comms, Gunny, Wingman).
Dialog: Displays sliders for each walking player, updates SquadState ratings.
Provider Usage:
Consumer<SquadState>: Accesses and updates dailyRatings and allTimeRatings.
Dependencies:
flutter/material.dart, provider.
Custom: squad_state.dart.
Notes:
Ratings range 1-10; defaults to last value or 1.
Updates both daily and all-time ratings in SquadState on submit.
Uses StatefulBuilder for dialog state management.
