File Summaries Recap
Core App
main.dart: App entry point; initializes Firebase, sets up SquadState and ChatState with MultiProvider, and defines a dark theme with cyan accents.
setup_screen.dart: Initial screen for anonymous sign-in and name setup, navigates to SquadQueuePage after storing yourName.
squad_state.dart: Central state management (ChangeNotifier) for squad data (spots, timers, members, game history, ratings, etc.), synced with Firestore.
Navigation
squad_queue_page.dart: Main navigation hub with a swipeable PageView (Performance, Availability, Squad, Chat, Placeholder) and animated bottom nav bar.
Squad Management
squad_tab.dart: UI for squad spots, peacock status, and member list; includes claiming, locking, and settings (clear, reset, ban).
rating_dialog.dart: Dialog for rating squad members (Vibes, Comms, Gunny, Wingman) after games, updates SquadState.
utils.dart: Helpers for timer formatting, badge display (turkey, duck, chicken), and average calculation.
Chat
chat_screen.dart: Full chat interface with text, media, audio messaging, reactions, and group options; uses ChatState and SquadState.
message_bubble.dart: Renders chat messages with text, media (image/video/audio), and reactions; supports tap/long-press actions.
chat_input_bar.dart: Chat input UI with text field, media, record, and send buttons; uses callbacks for actions.
chat_service.dart: Backend chat operations (send messages, upload media, mark delivered) with Firestore and Storage.
message.dart: Data model for chat messages with serialization and utility methods.
chat_state.dart: Manages chat UI state (typing, recording, uploading, sending) with ChangeNotifier.
Performance
performance_hub_tab.dart: Tabbed view for personal stats (K/D, win rate, trends) and leaderboards, using SquadState data.
Availability
availability_tab.dart: Schedules and displays availability with calendar, recurring events, notifications, and invites.
schedule_dialog.dart: Dialog for setting availability (time, date, repeat, invite, alert).
Utilities & Services
app_theme.dart: Defines static color constants and a minimal dark theme.
notification_service.dart: Manages Firebase Cloud Messaging for push notifications.
Key Insights
State Management: SquadState (app-wide squad data) and ChatState (chat-specific) use ChangeNotifier and Provider for reactive UI updates.
Firebase Integration: Firestore for real-time data (squad state, chat, schedules), Storage for media, Auth for anonymous sign-in.
UI Features: Swipe navigation, animated nav bar, charts (fl_chart), media playback (audioplayers, video_player), and custom dialogs.
Real-Time Features: Chat typing indicators, squad timers, availability scheduling, and notifications (firebase_messaging).
Assets: Uses icons (performance.png, sword.png, etc.) and sounds (victory.mp3, turkey.wav) for feedback.
