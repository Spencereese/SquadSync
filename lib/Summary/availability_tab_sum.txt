File Name: availability_tab.dart
Purpose: Manages and displays user availability scheduling with a calendar and event breakdowns.
Key Components:
AvailabilityTab (StatelessWidget): Main widget with calendar, day breakdown, and scheduling FAB.
_scheduleAvailabilityDialog: Opens dialog to schedule events and handles recurring logic.
_addEvent: Adds event to Firestore and SquadState.
_voteForEvent: Increments event votes in Firestore.
_clearAllAvailabilities: Deletes user’s scheduled events.
_scheduleNotification: Sets local notifications for events.
_sendInvites: Sends invites via Firestore.
_buildCalendar, _buildDayBreakdown, _buildPlayerTile, _buildClearButton: UI builders.
Provider Usage:
Uses Consumer<SquadState> to access and update squadState.scheduledTimes.
SquadState manages scheduled events list and Firestore sync.
Dependencies:
flutter/material.dart, table_calendar, cloud_firestore, intl, timezone, flutter_local_notifications, firebase_auth, provider.
Custom: schedule_dialog.dart, squad_state.dart.
Notes:
Relies on Firebase Auth for user ID and Firestore for event storage.
Handles recurring events (daily, weekly, monthly) over 30 days.
Notifications use timezone America/New_York.
UI updates require squadState.updateFirestore() for consistency.
