File Name: performance_hub_tab.dart
Purpose: Displays personal game stats and leaderboards with charts and metrics.
Key Components:
PerformanceHubTab (StatelessWidget): Tabbed view with Personal Stats and Leaderboards.
GameStats (class): Data model for stats (K/D, win rate, kills, deaths, chart spots).
PersonalStatsView (StatelessWidget): Shows personal K/D, win rate, kills, and trends.
_calculateStats: Computes stats from squadState.gameHistory.
_MetricCard: Displays a single stat metric.
_Chart: Renders line chart for K/D or win rate trends.
LeaderboardsView (StatelessWidget): Lists squad and global leaderboards by wins.
_calculateLeaderboard: Sorts members by wins from gameHistory.
Provider Usage:
Consumer<SquadState>: Accesses gameHistory and squadMembers for stats and leaderboards.
Dependencies:
flutter/material.dart, fl_chart, provider.
Custom: squad_state.dart.
Notes:
Two-tab interface: Personal Stats (charts + metrics) and Leaderboards (squad + global).
Charts use fl_chart with dynamic K/D and win rate trends from game history.
Global leaderboard mirrors squad data (placeholder; real app needs server fetch).
Debug prints for build tracking.
